第一项任务：
1、本地仓库初始化：git init

2、添加仓库说明 README.md 并编写基本内容，添加忽略文件 .gitignore 并编写基本内容（具体内容可以借助 AI 完成）

3、本地添加到暂存区：git add .

4、本地提交：git commit -m “提交信息”，注意规范化提交

5、Github 远程创建同名仓库

6、本地和远程建立关联：git remote add origin git@github.com：你的用户名/你的仓库名.git

7、推送到远程的 main 分支：git push -u origin main

8、成功后，查看远程仓库的信息，以及 Commits

第二项任务：

一、Git 本地仓库初始化
1. 初始化本地 git 仓库
打开终端，进入你的项目文件夹，如 frontend-learning，执行命令

 git init
执行完成会生成隐藏文件夹 .git，代表本地仓库初始化成功。

2. 创建  README.md 和  .gitignore
README.md（仓库说明）
新建文件 README.md，写入基础内容示例：

 # 前端工程化学习仓库
 > 本仓库用于前端工程化学习练习，记录学习过程
 
 ## 项目介绍
 练习 Vue 基础，包含字面量测试、Vite 创建 Vue 项目、Vue 基础语法等。
 
 ## 技术栈
 - Vite
 - Vue3
.gitignore git 忽略文件
新建 .gitignore 文件，下面是前端项目通用模板，这些文件不会被 git 追踪提交

 # node依赖
 node_modules/
 
 # 构建产物
 dist/
 build/
 
 # 本地环境变量
 .env
 .env.local
 
 # IDE配置
 .vscode/
 .idea/
 
 # 系统文件
 .DS_Store
 *.log
3. 添加到暂存区
 git add .
代表把当前目录下所有变更文件加入暂存区。

4. 本地提交（规范提交信息）
规范提交格式：

类型: 描述
常用类型：

feat：新功能

docs：文档

fix：修复

chore：构建配置

执行命令，本地提交

 git commit -m "docs: 初始化仓库，添加 README 和 gitignore"
二、GitHub 创建远程仓库并关联
5. Github 网页端创建同名仓库
GitHub 页面，New 新建仓库

仓库名和本地文件夹名字保持一致

不要勾选 Add a README file（本地已经有 README）

选择 Public / Private，点击创建仓库

6. 本地关联远程仓库
SSH 方式（推荐，配置好 ssh 密钥不需要输密码）

 git remote add origin git@github.com:你的用户名/你的仓库名.git
查看远程关联是否成功

 git remote -v
7. 推送到远程 main 分支
 git push -u origin main
第一次推送需要使用 -u 设置上游，后续可以直接输入 git push 即可推送。

8. 验证
浏览器打开 github 仓库页面：

可以看到 README 和 .gitignore 文件

切换到 Commits ，可以查看提交记录。



三、第一个子项目：Vue3 起步练习
前提：本地安装好 node.js

练习 1：原生字面量方式体验 Vue3（不使用构建工具）
本地 frontend-learning 仓库新建文件夹 01-vue-literal，创建 index.html，如下：

 <!DOCTYPE html>
 <html lang="zh-CN">
 <head>
   <meta charset="UTF-8">
   <title>Vue字面量入门</title>
   <!-- CDN引入Vue3 -->
   <script src="https://unpkg.com/vue@3/dist/vue.global.js"></script>
 </head>
 <body>
   <div id="app">
     <h1>{{ msg }}</h1>
     <p>计数：{{ count }}</p>
     <button @click="add">点我+1</button>
   </div>
 
   <script>
     const { createApp } = Vue
     // 字面量创建Vue实例
     createApp({
       data() {
         return {
           msg: 'Vue字面量练习',
           count: 0
         }
       },
       methods:{
         add(){
           this.count++
         }
       }
     }).mount('#app')
   </script>
 </body>
 </html>
浏览器打开 html 文件即可运行，这是不借助打包工具直接使用 Vue。

练习 3：Vue 基础语法学习清单，可以在 02‑vite‑vue‑demo 中练习
插值语法 {{ }}

v‑bind 属性绑定

v‑on 事件绑定 @click

v‑if /v‑else 条件渲染

v‑for 列表循环渲染

v‑model 双向绑定

计算属性 computed

侦听器 watch

示例片段，直接替换 App.vue 练习：

 <template>
   <div>
     <!-- 插值 -->
     <p>姓名：{{ name }}</p>
     <!-- 属性绑定 -->
     <img v-bind:src="imgUrl" alt="">
     <!-- 事件 -->
     <button @click="changeName">修改名字</button>
     <!-- 双向绑定 -->
     <input v-model="name"/>
     <!-- 条件 -->
     <p v-if="isShow">显示内容</p>
     <!-- 循环 -->
     <ul>
       <li v-for="item in list" :key="item.id">{{ item.title }}</li>
     </ul>
   </div>
 </template>
 
 <script setup>
 import { ref } from 'vue'
 const name = ref("张三")
 const imgUrl = ref("https://picsum.photos/100")
 const isShow = ref(true)
 const list = ref([
   {id:1, title:"Vue学习1"},
   {id:2, title:"Vue学习2"}
 ])
 
 const changeName = ()=>{
   name.value = "李四"
 }
 </script>
写完练习继续规范提交：

 git add .
 git commit -m "feat: 练习 vue 基础指令语法"
 git push
